# DREAM COMPUTE

Independent compute control plane and worker orchestration for DREAM AI.

Source is stored in the ordered `dream-compute-source.part*` text chunks in this branch.
Render reassembles the base64-compressed tar archive before installing and starting the service.
After deployment, open `dream-compute/README.md` for worker installation, API details and reliability limits.

This branch is isolated from `main` and `dream-host-runtime`.
